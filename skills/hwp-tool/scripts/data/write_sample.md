# 가온시 주민 안내 누리집 사업계획서

## 1. 신청인

| 항목 | 내용 |
|---|---|
| 상호 | 가온정보 |
| 대표자 | 홍길동 |
| 사업장 소재지 | 가온시 나래구 다솜로 12, 3층 301호(바람동) |
| 사업 형태 | 개인사업자(2024. 3. 1. 개업) |
| 종사자 | 2명(대표자 포함) |

## 2. 사업 목적

가온정보가 운영하는 생활정보 누리집 「가온안내」(https://gaon-guide.example.org/notice/list?page=1)에서 공공기관이 공개한 안내문을 주민이 지역·분야·날짜로 쉽게 찾아볼 수 있게 한다. 누리집은 공공 자료를 바탕으로 **생활 정보**와 계산기를 무료로 제공한다.

## 3. 수지예산 (첫 1년)

| 구분 | 항목 | 금액(원) | 비고 |
|---|---|---:|---|
| 수입 | 이용료 | 0 | 무료 제공 |
| 수입 | 광고 수입 | 1,200,000 | 월 10만 원 계획 |
| 수입 | 합계 | 1,200,000 | |
| 지출 | 도메인 | 20,000 | 연 1회 |
| 지출 | 서버 | 0 | 무료 요금제 |
| 지출 | 인건비 | 0 | 대표자 직접 운영 |
| 지출 | 합계 | 20,000 | |

운영비는 적고, 광고 수입이 계획보다 적더라도 다른 사업 수입으로 충당한다.

## 4. 지킬 일

1. 누리집 화면에 신고번호를 표시한다.
2. 출처가 확실하지 않은 안내문은 싣지 않는다.
3. "상담", "추천", ‘지원’ 같은 표현을 쓰지 않는다.
4. 업무상 알게 된 이용자의 비밀을 누설하지 않는다.
